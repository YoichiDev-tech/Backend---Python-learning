# Learning Documentation

This directory contains written explanations, technical notes
and reference material collected throughout my Python learning journey.

## Purpose

The goal is to create a reliable reference for concepts I have learned, common mistakes, useful techniques, and important programming principles.

## Documentation Structure

- `python-fundamentals.md` — Summaries of fundamental Python concepts.
- `best-practices.md` — Coding conventions, readability, and maintainability.
- `troubleshooting.md` — Common errors, their causes, and solutions.
- `shortcuts.md` — Useful VS Code and terminal shortcuts.

## Note-Taking Principles

For each important concept, document:

1. **Definition:** What is it?
2. **Purpose:** Why is it useful?
3. **Syntax:** How is it written?
4. **Example:** A small, practical example.
5. **Key takeaways:** What should I remember?
6. **Common mistakes:** What should I avoid?
7. **Practical application:** Where could I use it?

Documentation should be concise, accurate, and written in my own words.
Code examples should be tested whenever practical.
